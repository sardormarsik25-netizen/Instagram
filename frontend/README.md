# Instagram clone (nf-2956)

React + Vite asosidagi o'quv loyihasi.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Tekshiruv

```bash
npm run lint
npm run build
```

## Texnologiyalar

- React 18, Vite 6
- Tailwind CSS 3, DaisyUI 4 (`instagram` va `instagram-dark` theme'lari)
- react-router-dom 6.3
- Redux Toolkit + redux-persist
- react-icons, react-toastify

## Sahifalar

Home, Reels, Chat, Search, Notifications, Post, Profile. Login/Register va route guard mavjud.
Login va ro‘yxatdan o‘tish loyiha backendiga ulangan. Lokal sozlash uchun asosiy `README.md` fayliga qarang.

Vazifalar: `tasks.md`.
